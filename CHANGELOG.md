# Changelog

All notable changes to PhantomMirror will be documented in this file.

## [0.1.0] - 2026-06-30

### Added
- Multi-device Android mirroring via ADB + scrcpy
- iOS screen mirroring via AirPlay (UxPlay headless)
- Real-time H.264 / H.265 hardware-accelerated video decoding (WebCodecs)
- Touch/swipe/click control from desktop to Android devices
- USB and WiFi (ADB over TCP) connection modes
- Wireless ADB device pairing (Android 11+)
- mDNS auto-discovery of ADB-over-WiFi devices
- Local network port-scan fallback discovery
- Grid, Focus, and Single layout modes
- Drag-to-reorder device tiles
- Screen recording (WebM/VP9)
- Clipboard push/pull between desktop and Android
- File drag-and-drop transfer to Android (/sdcard/Download)
- Android as extended display (via Android agent)
- Device info panel (battery, Android version, storage, FPS)
- Settings drawer (theme, quality presets, auto-reconnect)
- Dark/Light/Auto theme
- FPS counter overlay
- Keyboard shortcuts (F11 fullscreen, Ctrl+1/2/3 layout, Ctrl+S screenshot, Ctrl+R rotate)
